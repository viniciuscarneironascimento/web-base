# 📘 Projeto: web-base

🔗 [Acesse o repositório no GitHub](https://github.com/viniciuscarneironascimento/web-base)

---

## 📝 Descrição

Repositório do portfólio dedicado ao aprendizado prático de fundamentos da web. O projeto consiste em uma aplicação web simples de **cadastro de alunos**, que faz parte do curso **QA Ninja** e tem como objetivo proporcionar uma base sólida sobre o funcionamento de aplicações web — um conhecimento essencial para profissionais de QA que trabalham com testes E2E e inspeção de elementos.

---

## 🚀 Resultados Alcançados

- Aprofundei meus conhecimentos nos fundamentos de **HTML, CSS e JavaScript** voltados para profissionais de QA.
- Utilizei **HTML5** com uso de tags como `<form>`, `<input>`, `<table>` e `<div>`.
- Utilizei **CSS** para estilização com classes como `.table`, `.label`, além de personalização de inputs e botões.
- Utilizei **JavaScript** para manipulação de arrays, tratamento de eventos e criação de métodos para cadastro e exclusão dinâmica de dados.
- Utilizei **Vue.js** Framework progressivo utilizado via `<script src="js/vue.js">` para tornar a aplicação reativa.
